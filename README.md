5.1 ANTs N4BiasFieldCorrection for Intensity Inhomogeneity Mitigation in T1-Weighted Volumes
The Challenge of Intensity Inhomogeneity
Magnetic resonance imaging (MRI) suffers from a fundamental artifact: intensity inhomogeneity, also known as bias field or RF inhomogeneity. This artifact manifests as a smooth, spatially varying intensity gradient across the image, independent of tissue properties. The causes include:
1.	RF coil non-uniformity: The transmit and receive fields of RF coils are not perfectly uniform across the imaging volume
2.	Dielectric effects: The interaction of RF fields with the patient's tissues causes standing wave patterns, particularly at high field strengths (3T and above)
3.	Eddy currents: Time-varying gradients induce currents in conductive structures, affecting the local field
4.	Patient positioning: Small variations in patient position relative to the coil
The N4BiasFieldCorrection Algorithm
The Advanced Normalization Tools (ANTs) N4BiasFieldCorrection algorithm is a state-of-the-art method for correcting intensity inhomogeneities. It is an extension of the original N3 algorithm (Sled et al., 1998) with significant improvements:
Core Principles:
1.	B-Spline Approximation: The bias field is modeled as a smooth, slowly varying multiplicative field represented by a B-spline basis. This provides a flexible yet regularized representation.
2.	Maximum Likelihood Estimation: The algorithm iteratively estimates the bias field by maximizing the likelihood of the observed image given a tissue probability model.
3.	Multi-Resolution Processing: The algorithm operates at multiple resolutions, allowing for efficient convergence and robust estimation.
Mathematical Formulation:
The observed image intensity at voxel position xx is modeled as:
Iobserved(x)=Itrue(x)⋅B(x)+η(x)Iobserved(x)=Itrue(x)⋅B(x)+η(x)
where:
•	Itrue(x)Itrue(x) is the true tissue intensity
•	B(x)B(x) is the multiplicative bias field
•	η(x)η(x) is additive noise
The algorithm iteratively estimates the bias field using an Expectation-Maximization (EM) framework, with B-spline regularization to ensure smoothness.

Using a sliding window approach:
python
from scipy.ndimage import uniform_filter

def compute_local_shannon_entropy(data_norm, window_size=3):
    """
    Computes localized Shannon entropy approximation across a 3D MRI volume
    using local mean probability estimations.
    """
    eps = 1e-9
    p = np.clip(data_norm, 0, 1)
    
    # Local probability density estimation via moving window average
    local_mean = uniform_filter(p, size=window_size)
    local_sq_mean = uniform_filter(p**2, size=window_size)
    local_var = np.maximum(local_sq_mean - local_mean**2, 0)
    
    # Map local variance to entropy state
    local_p = np.clip(local_mean, eps, 1.0 - eps)
    entropy_field = - (local_p * np.log(local_p) + (1.0 - local_p) * np.log(1.0 - local_p + eps))
    
    return entropy_field

def coregister_to_mni152(structural_path, entropy_path, pet_path):
    """
    Co-register structural entropy and PET images to MNI152 space.

    # Load images
    structural = ants.image_read(structural_path)

        moving=entropy,

    )

        fixed=mni_template,
        moving=pet,
        transformlist=registration['fwdtransforms']
    )

        'structural_mni': registration['warpedmovout'],

def compute_voxelwise_correlation(entropy_grad, pet_suv, roi_mask=None):
    """
    Compute voxel-wise Pearson correlation between entropy gradient magnitude
    and PET SUV.
    
    Parameters:
    - entropy_grad: 3D array of entropy gradient magnitudes
    - pet_suv: 3D array of PET SUV values
    - roi_mask: Optional 3D binary mask for ROI

    - r: Pearson correlation coefficient
    - p: p-value

    from scipy.stats import pearsonr
    import numpy as np

        pet_vec = pet_suv[roi_mask].flatten()

    entropy_vec = entropy_vec[mask]
    pet_vec = pet_vec[mask]
    
    return pearsonr(entropy_vec, pet_vec)

def compute_entropy_metabolic_overlap(entropy_decline, hypometabolism_map, threshold=0.3):
    """
    Compute spatial overlap between entropy decline and hypometabolism.
    
    Parameters:
    - entropy_decline: 3D array of entropy decline values
    - hypometabolism_map: 3D array of hypometabolism values
    - threshold: Threshold for binary overlap
    
    Returns:
    - overlap_ratio: Fraction of overlap
    - dice_coefficient: Dice similarity coefficient
    """
    # Binarize
    entropy_binary = entropy_decline > threshold
    hypomet_binary = hypometabolism_map > threshold
    
    # Compute overlap
    intersection = np.sum(entropy_binary & hypomet_binary)
    union = np.sum(entropy_binary | hypomet_binary)
    
    overlap_ratio = intersection / union if union > 0 else 0
    dice = 2 * intersection / (np.sum(entropy_binary) + np.sum(hypomet_binary))
    
    return {'overlap_ratio': overlap_ratio, 'dice': dice}

8.1 Task-Free Functional Variance Mapping and Execution Hotspot Tracking
Functional MRI (fMRI) and BOLD Signal
Blood Oxygenation Level Dependent (BOLD) fMRI measures changes in blood flow and oxygenation that accompany neural activity. The BOLD signal is a proxy for neural activity, with higher BOLD signal indicating increased neural activity.
Task-Free (Resting-State) fMRI
Resting-state fMRI measures spontaneous fluctuations in BOLD signal when the subject is not performing any specific task. These fluctuations reflect intrinsic functional connectivity networks.
Key Resting-State Networks:
1.	Default Mode Network (DMN): Medial prefrontal cortex, posterior cingulate, hippocampus
2.	Executive Control Network: Dorsolateral prefrontal cortex, parietal lobe
3.	Salience Network: Anterior cingulate, insula
Variance Mapping
BOLD variance captures the temporal dynamics of resting-state activity:
Var(BOLD)=1N−1∑t=1N(BOLDt−BOLD‾)2Var(BOLD)=N−11∑t=1N(BOLDt−BOLD)2
High variance indicates dynamic, fluctuating neural activity, while low variance indicates stable, quiet activity.

def detect_functional_hotspots(bold_data, threshold_percentile=95):
    """
    Detect regions with high BOLD variance (functional hotspots).
    
    Parameters:
    - bold_data: 4D array of BOLD time series (x, y, z, t)
    - threshold_percentile: Percentile threshold for hotspot definition
    
    Returns:
    - variance_map: 3D array of BOLD variance
    - hotspot_mask: 3D binary mask of hotspots
    """
    import numpy as np
    
    # Compute temporal variance
    variance_map = np.var(bold_data, axis=3)
    
    # Define hotspot threshold
    threshold = np.percentile(variance_map, threshold_percentile)
    hotspot_mask = variance_map > threshold
    
    return {'variance_map': variance_map, 'hotspot_mask': hotspot_mask}

4.	Statistical Outliers: Subjects deviating significantly from population norms
Anomaly Detection Algorithms
1. Statistical Threshold Detection
python
def detect_entropy_anomaly(gradient_value, roi_mean, roi_std, threshold_sigma=2.5):
    """
    Detect if an entropy gradient value is an anomaly.
    
    Parameters:
    - gradient_value: New entropy gradient value
    - roi_mean: Population mean for this ROI
    - roi_std: Population standard deviation
    - threshold_sigma: Number of standard deviations for anomaly
    
    Returns:
    - is_anomaly: Boolean
    - z_score: Standardized score
    """
    z_score = (gradient_value - roi_mean) / roi_std
    is_anomaly = abs(z_score) > threshold_sigma
    return {'is_anomaly': is_anomaly, 'z_score': z_score}
2. Longitudinal Change Detection
python
def detect_longitudinal_anomaly(previous_values, new_value, trend_threshold=0.15):
    """
    Detect if a new value deviates significantly from longitudinal trend.
    
    Parameters:
    - previous_values: List of previous entropy gradient values
    - new_value: New entropy gradient value
    - trend_threshold: Maximum allowed deviation from trend
    
    Returns:
    - is_anomaly: Boolean
    - deviation: Deviation from expected trend
    """
    if len(previous_values) < 2:
        return {'is_anomaly': False, 'deviation': 0}
    
    # Fit linear trend
    t = np.arange(len(previous_values))
    trend = np.polyfit(t, previous_values, 1)
    expected_next = np.polyval(trend, len(previous_values))
    
    deviation = new_value - expected_next
    is_anomaly = abs(deviation) > trend_threshold
    
    return {'is_anomaly': is_anomaly, 'deviation': deviation}
3. Correlation Break Detection
python
def detect_correlation_break(entropy_values, pet_values, window_size=10, threshold=0.3):
    """
    Detect if entropy-PET correlation breaks down.
    
    Parameters:
    - entropy_values: List of entropy gradient values
    - pet_values: List of PET SUV values
    - window_size: Rolling window size
    - threshold: Minimum correlation threshold
    
    Returns:
    - is_break: Boolean
    - correlation: Current rolling correlation
    """
    from scipy.stats import pearsonr
    
    if len(entropy_values) < window_size:
        return {'is_break': False, 'correlation': 0}
    
    recent_entropy = entropy_values[-window_size:]
    recent_pet = pet_values[-window_size:]
    r, _ = pearsonr(recent_entropy, recent_pet)
    
    is_break = r < threshold
    return {'is_break': is_break, 'correlation': r}

import requests

            'threshold': threshold,

        }

        return response.status_code == 200

        """
        Comprehensive anomaly detection with alerting.
        """
        # Statistical anomaly
        stat_check = detect_entropy_anomaly(
            new_value, 
            population_stats['mean'], 
            population_stats['std']
        )
        
        if stat_check['is_anomaly']:

                'critical'
            )
        
        # Longitudinal anomaly
        if len(historical_data) >= 3:
            long_check = detect_longitudinal_anomaly(historical_data, new_value)
            if long_check['is_anomaly']:
                self.send_alert(
                    'longitudinal_break',
                    subject_id, roi_name,
                    new_value,
                    long_check['deviation'],
                    'warning'
                )
        
        return {
            'statistical_check': stat_check,
            'longitudinal_check': long_check if len(historical_data) >= 3 else None
        }

import pyvista as pv
import nibabel as nib
import numpy as np

class NeuroThermodynamicRenderer:
    """
    Multi-channel 3D renderer for the Neuro-Thermodynamic Atlas.
    """
    
    def __init__(self):
        self.plotter = None
        
    def load_volume(self, nifti_path):
        """Load NIfTI volume and convert to PyVista UniformGrid."""
        img = nib.load(nifti_path)
        data = img.get_fdata()
        affine = img.affine
        
        dims = data.shape
        spacing = np.abs(np.diag(affine)[:3])
        origin = affine[:3, 3]
        
        grid = pv.UniformGrid()
        grid.dimensions = dims
        grid.spacing = spacing
        grid.origin = origin
        grid.point_data["values"] = data.flatten(order="F")
        
        return grid
    
    def render_atlas(self, t1_path, entropy_path, pet_path, fmri_path):
        """
        Render the full neuro-thermodynamic atlas.
        """
        # Initialize plotter
        self.plotter = pv.Plotter(window_size=(1200, 800))
        
        # Load volumes
        t1_grid = self.load_volume(t1_path)
        entropy_grid = self.load_volume(entropy_path)
        pet_grid = self.load_volume(pet_path)
        fmri_grid = self.load_volume(fmri_path)
        
        # Step 1: Structural layer (grayscale)
        self.plotter.add_volume(
            t1_grid, 
            cmap="gray", 
            opacity="linear",
            label="Structural T1"
        )
        
        # Step 2: Entropy isolines (cyan contours)
        contours = entropy_grid.contour([0.2, 0.4, 0.6, 0.8])
        self.plotter.add_mesh(
            contours, 
            color="cyan", 
            line_width=2.0,
            label="Entropy Isolines"
        )
        
        # Step 3: PET metabolic overlay (hot colormap)
        self.plotter.add_volume(
            pet_grid, 
            cmap="hot", 
            opacity="sigmoid",
            label="PET Metabolism"
        )
        
        # Step 4: fMRI variance overlay (coolwarm)
        self.plotter.add_volume(
            fmri_grid, 
            cmap="coolwarm", 
            opacity="sigmoid",
            label="fMRI Variance"
        )
        
        # Step 5: Interactive slicing planes
        self.plotter.add_mesh(
            entropy_grid.slice('x'), 
            cmap="viridis", 
            opacity=0.7,
            label="Sagittal Slice"
        )
        self.plotter.add_mesh(
            pet_grid.slice('y'), 
            cmap="hot", 
            opacity=0.5,
            label="Coronal Slice"
        )
        self.plotter.add_mesh(
            fmri_grid.slice('z'), 
            cmap="coolwarm", 
            opacity=0.5,
            label="Axial Slice"
        )
        
        # Add lighting and camera
        self.plotter.enable_shadows()
        self.plotter.camera_position = 'iso'
        
        # Legend
        self.plotter.add_legend()
        
        return self.plotter
    
    def render_roi_panels(self, t1_path, entropy_path, pet_path, fmri_path):
        """
        Render side-by-side ROI panels.
        """
        # Load volumes
        t1_grid = self.load_volume(t1_path)
        entropy_grid = self.load_volume(entropy_path)
        pet_grid = self.load_volume(pet_path)
        fmri_grid = self.load_volume(fmri_path)
        
        # ROI configurations
        rois = [
            {'name': 'Hippocampus', 'contour_level': 0.3, 'slice': 'x'},
            {'name': 'Prefrontal Cortex', 'contour_level': 0.2, 'slice': 'y'},
            {'name': 'Parietal Lobe', 'contour_level': 0.25, 'slice': 'z'}
        ]
        
        # Create multi-panel plotter
        plotter = pv.Plotter(shape=(1, 3))
        
        for i, roi in enumerate(rois):
            plotter.subplot(0, i)
            
            # Structural background
            plotter.add_volume(t1_grid, cmap="gray", opacity="linear")
            
            # Entropy isolines
            contours = entropy_grid.contour([roi['contour_level']])
            plotter.add_mesh(contours, color="cyan", line_width=2.0)
            
            # PET overlay
            plotter.add_volume(pet_grid, cmap="hot", opacity=0.5)
            
            # fMRI overlay
            plotter.add_volume(fmri_grid, cmap="coolwarm", opacity=0.4)
            
            # Add ROI label
            plotter.add_text(roi['name'], font_size=12, position='upper_left')
            
            # Add slice plane
            slice_plane = entropy_grid.slice(roi['slice'])
            plotter.add_mesh(slice_plane, cmap="viridis", opacity=0.6)
        
        return plotter
    
    def export_snapshot(self, output_path):

            self.plotter.screenshot(output_path, window_size=(1200, 800))
        else:
            raise ValueError("No plotter initialized")
    
    def interactive_view(self):
        """Display interactive viewer."""

            self.plotter.show()

            raise ValueError("No plotter initialized")

                        db: sqlite3.Connection = Depends(get_db)):
    """Retrieve population statistics for an ROI."""
    cursor = db.cursor()
    
    query = """
        SELECT s.baseline_diagnosis, a.timepoint,
               AVG(sem.mean_gradient_magnitude) AS mean_gradient,
               STDDEV(sem.mean_gradient_magnitude) AS std_gradient,
               AVG(mfm.pet_suv_mean) AS mean_suv,
               STDDEV(mfm.pet_suv_mean) AS std_suv,
               AVG(mfm.fmri_bold_variance) AS mean_bold,
               STDDEV(mfm.fmri_bold_variance) AS std_bold,
               COUNT(*) AS n_subjects
        FROM Subjects s
        JOIN Acquisition_Sessions a ON s.subject_id = a.subject_id
        JOIN Structural_Entropy_Metrics sem ON a.session_id = sem.session_id
        LEFT JOIN Metabolic_Functional_Metrics mfm ON a.session_id = mfm.session_id 
            AND sem.roi_name = mfm.roi_name
        WHERE sem.roi_name = ?
    """
    params = [roi_name]
    
    if cohort:
        query += " AND s.cohort_source = ?"
        params.append(cohort)
    
    query += " GROUP BY s.baseline_diagnosis, a.timepoint ORDER BY a.timepoint"
    
    cursor.execute(query, params)
    results = [dict(row) for row in cursor.fetchall()]
    
    return {
        "roi_name": roi_name,
        "cohort": cohort,
        "statistics": results
    }

class AutomationOrchestrator:
    """
    Orchestrates automated snapshot generation and alerting.
    """
    
    def __init__(self, renderer, alert_system):
        self.renderer = renderer
        self.alert_system = alert_system
        self.active_workflows = {}
    
    async def process_new_session(self, session_id: str, data_paths: Dict[str, str]):
        """
        Process a new session: generate metrics, snapshots, and check for anomalies.
        """
        workflow_id = f"workflow_{session_id}_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
        self.active_workflows[workflow_id] = {"status": "running", "steps": []}
        
        try:
            # Step 1: Generate structural entropy metrics
            entropy_result = await self.generate_entropy_metrics(data_paths['structural'])
            self.active_workflows[workflow_id]['steps'].append({
                'step': 'entropy_metrics',
                'status': 'completed',
                'data': entropy_result
            })
            
            # Step 2: Generate metabolic metrics
            metabolic_result = await self.generate_metabolic_metrics(data_paths['pet'], data_paths['fmri'])
            self.active_workflows[workflow_id]['steps'].append({
                'step': 'metabolic_metrics',
                'status': 'completed',
                'data': metabolic_result
            })
            
            # Step 3: Compute correlation matrices
            correlation_result = await self.compute_correlations(
                entropy_result, metabolic_result
            )
            self.active_workflows[workflow_id]['steps'].append({
                'step': 'correlations',
                'status': 'completed',
                'data': correlation_result
            })
            
            # Step 4: Generate volumetric snapshots
            snapshot_paths = await self.generate_snapshots(
                data_paths['structural'],
                data_paths['entropy'],
                data_paths['pet'],
                data_paths['fmri']
            )
            self.active_workflows[workflow_id]['steps'].append({
                'step': 'snapshots',
                'status': 'completed',
                'data': snapshot_paths
            })
            
            # Step 5: Anomaly detection
            anomalies = await self.check_anomalies(
                entropy_result, metabolic_result, correlation_result
            )
            
            # Step 6: Alert if anomalies found
            if anomalies['has_anomalies']:
                for anomaly in anomalies['anomalies']:
                    await self.alert_system.send_alert(
                        alert_type=anomaly['type'],
                        subject_id=anomaly['subject_id'],
                        roi_name=anomaly['roi_name'],
                        value=anomaly['value'],
                        threshold=anomaly['threshold'],
                        severity=anomaly['severity']
                    )
            
            # Step 7: Ingest into database
            await self.ingest_into_database(
                session_id, entropy_result, metabolic_result, 
                correlation_result, snapshot_paths
            )
            
            self.active_workflows[workflow_id]['status'] = 'completed'
            return self.active_workflows[workflow_id]

        slice_idx = int(self.t1_data.shape[1] * self.current_slice / 100)
        t1_slice = self.t1_data[:, slice_idx, :]
        entropy_slice = self.entropy_data[:, slice_idx, :]
        
        self.plotter.add_image(t1_slice, cmap="gray")
        
        if entropy_slice is not None:
            from skimage import measure
            contours = measure.find_contours(entropy_slice, 0.4)
            for contour in contours:
                self.plotter.add_points(contour, color="cyan", point_size=1)
    
    def add_sagittal_slice(self):
        """Add sagittal slice with entropy overlay."""
        slice_idx = int(self.t1_data.shape[0] * self.current_slice / 100)
        t1_slice = self.t1_data[slice_idx, :, :]
        entropy_slice = self.entropy_data[slice_idx, :, :]
        
        self.plotter.add_image(t1_slice, cmap="gray")
        
        if entropy_slice is not None:
            from skimage import measure
            contours = measure.find_contours(entropy_slice, 0.4)
            for contour in contours:
                self.plotter.add_points(contour, color="cyan", point_size=1)
    
    def add_3d_view(self):
        """Add 3D volume rendering with clipping."""
        # Convert to UniformGrid
        t1_grid = self.to_uniform_grid(self.t1_data)
        
        # Add volume with clipping
        self.plotter.add_volume(
            t1_grid, 
            cmap="gray", 
            opacity="linear"
        )
        
        # Add entropy contours
        entropy_grid = self.to_uniform_grid(self.entropy_data)
        contours = entropy_grid.contour([0.4])
        self.plotter.add_mesh(contours, color="cyan", line_width=1.5)
    
    def to_uniform_grid(self, data):
        """Convert numpy array to PyVista UniformGrid."""
        dims = data.shape
        grid = pv.UniformGrid()
        grid.dimensions = dims
        grid.spacing = (1, 1, 1)
        grid.point_data["values"] = data.flatten(order="F")
        return grid
    
    def set_slice_position(self, orientation, position):
        """Update slice position interactively."""
        if orientation in ['axial', 'coronal', 'sagittal']:
            self.current_orientation = orientation
            self.current_slice = position
            self.create_slicer()
    
    def interactive_controls(self):
        """Add interactive controls for slice navigation."""
        # This would be implemented with sliders in a GUI
        # For now, we create a simple function
        
        def update_slider(orient, value):
            self.set_slice_position(orient, value)

11.1 Docker Image Packaging for Isolated ANTs, FreeSurfer, and Rendering Environments
The Need for Containerization
The Neuro-Thermodynamic Atlas pipeline consists of multiple complex software components:
1.	ANTs - N4BiasFieldCorrection
2.	HD-BET - Deep learning skull stripping
3.	FreeSurfer - Cortical segmentation and parcellation
4.	Custom Python - Entropy gradient computation
5.	PyVista - 3D volumetric rendering
Each component has specific dependencies, versions, and computational requirements. Containerization with Docker ensures:
•	Reproducibility: Identical execution across environments
•	Isolation: No dependency conflicts
•	Scalability: Easy deployment on Kubernetes
•	Portability: Run anywhere (local, cloud, hybrid)

import logging
import json
from datetime import datetime

class PipelineLogger:
    """Structured logging for pipeline steps."""
    
    def __init__(self, service_name, session_id):
        self.service_name = service_name
        self.session_id = session_id
        self.logger = logging.getLogger(service_name)
    
    def log_step(self, step_name, status, details=None, error=None):
        """Log pipeline step with structured format."""
        log_entry = {
            'timestamp': datetime.now().isoformat(),
            'service': self.service_name,
            'session_id': self.session_id,
            'step': step_name,
            'status': status,
            'details': details,
            'error': error
        }
        
        if error:
            self.logger.error(json.dumps(log_entry))
        else:
            self.logger.info(json.dumps(log_entry))
    
    def log_metrics(self, roi_name, metrics):
        """Log computed metrics."""
        log_entry = {
            'timestamp': datetime.now().isoformat(),
            'service': self.service_name,
            'session_id': self.session_id,
            'roi_name': roi_name,
            'metrics': metrics,
            'type': 'metrics'
        }
        self.logger.info(json.dumps(log_entry))
    
    def log_anomaly(self, anomaly_type, roi_name, value, threshold, severity):
        """Log anomaly detection event."""
        log_entry = {
            'timestamp': datetime.now().isoformat(),
            'service': self.service_name,
            'session_id': self.session_id,
            'event_type': 'anomaly',
            'anomaly_type': anomaly_type,
            'roi_name': roi_name,
            'value': value,
            'threshold': threshold,
            'severity': severity
        }
        self.logger.warning(json.dumps(log_entry))

@app.task(bind=True, max_retries=3, default_retry_delay=60)
def run_full_pipeline(self, session_id, subject_id, t1_path, pet_path=None, fmri_path=None):
    """
    Orchestrate the complete neuro-thermodynamic pipeline.
    
    Parameters:
    - session_id: Unique session identifier
    - subject_id: Subject identifier
    - t1_path: Path to T1-weighted NIfTI file
    - pet_path: Optional path to PET NIfTI file
    - fmri_path: Optional path to fMRI NIfTI file
    """
    try:
        results = {}
        
        # Step 1: N4 Bias Correction
        corrected_path = run_n4_correction(t1_path, session_id)
        results['n4_corrected'] = corrected_path
        
        # Step 2: Skull Stripping
        brain_path = run_skull_stripping(corrected_path, session_id)
        results['brain'] = brain_path
        
        # Step 3: FreeSurfer Segmentation (submitted to dedicated queue)
        fs_result = run_freesurfer.apply_async(
            args=[session_id, subject_id, brain_path],
            queue='freesurfer'
        )
        fs_results = fs_result.get(timeout=7200)
        results['freesurfer'] = fs_results
        
        # Step 4: Entropy Gradient Computation
        entropy_path = compute_entropy_gradient(brain_path, session_id)
        results['entropy'] = entropy_path
        
        # Step 5: Multi-modal Integration (if PET/fMRI available)
        if pet_path and fmri_path:
            correlation_results = compute_correlations(
                entropy_path, pet_path, fmri_path, session_id
            )
            results['correlations'] = correlation_results
        
        # Step 6: Rendering
        render_results = render_atlas.apply_async(
            args=[session_id, entropy_path, pet_path, fmri_path],
            queue='rendering'
        )
        render_results = render_results.get(timeout=1800)
        results['rendering'] = render_results
        
        # Step 7: Database Ingest
        ingest_results = ingest_into_database(
            session_id, subject_id, results
        )
        results['database'] = ingest_results
        
        # Step 8: Anomaly Detection
        anomalies = check_anomalies(results)
        if anomalies['has_anomalies']:
            send_alerts(anomalies)
            results['anomalies'] = anomalies
        
        # Step 9: Update Metrics
        update_prometheus_metrics(results)
        
        return {
            'status': 'completed',
            'session_id': session_id,
            'subject_id': subject_id,
            'results': results,
            'timestamp': datetime.now().isoformat()
        }
        
    except Exception as exc:
        # Log error
        log_error(session_id, str(exc))
        # Retry
        self.retry(exc=exc)

@app.task(bind=True, max_retries=2)
def compute_entropy_gradient(self, brain_path, session_id):
    """Compute Shannon entropy gradient."""
    output_path = f"/app/data/entropy_gradients/{session_id}_entropy_gradient.nii.gz"
    os.makedirs(os.path.dirname(output_path), exist_ok=True)
    
    # Python script for entropy computation
    script = f"""
import nibabel as nib
import numpy as np

def compute_entropy_gradient(input_path, output_path):
    img = nib.load(input_path)
    data = img.get_fdata()
    data_norm = data / np.max(data)
    
    # Compute local entropy
    from scipy.ndimage import uniform_filter
    eps = 1e-9
    p = np.clip(data_norm, 0, 1)
    local_mean = uniform_filter(p, size=3)
    local_p = np.clip(local_mean, eps, 1.0 - eps)
    entropy = - (local_p * np.log(local_p) + (1.0 - local_p) * np.log(1.0 - local_p + eps))
    
    # Compute gradient
    grad = np.gradient(entropy)
    grad_magnitude = np.sqrt(sum(g**2 for g in grad))
    
    # Save
    res_img = nib.Nifti1Image(grad_magnitude.astype(np.float32), img.affine, img.header)
    nib.save(res_img, output_path)
    
compute_entropy_gradient("{brain_path}", "{output_path}")
"""
    
    try:
        result = subprocess.run(['python', '-c', script], check=True, capture_output=True, timeout=600)
        return output_path
    except subprocess.CalledProcessError as e:
        log_pipeline_error(session_id, 'entropy_computation', str(e))
        self.retry(exc=e)

import numpy as np
from typing import List, Tuple

class DifferentialPrivacy:
    """
    Differential privacy implementation for metadata sharing.
    """
    
    def __init__(self, epsilon: float = 1.0, delta: float = 1e-5):
        """
        Initialize differential privacy parameters.
        
        Parameters:
        - epsilon: Privacy budget (smaller = more privacy)
        - delta: Failure probability
        """
        self.epsilon = epsilon
        self.delta = delta
        self.sensitivity = 1.0  # Sensitivity of the query
    
    def add_laplace_noise(self, value: float) -> float:
        """Add Laplace noise to a query result."""
        scale = self.sensitivity / self.epsilon
        noise = np.random.laplace(0, scale)
        return value + noise
    
    def add_gaussian_noise(self, value: float) -> float:
        """Add Gaussian noise to a query result."""
        sigma = self.sensitivity * np.sqrt(2 * np.log(1.25 / self.delta)) / self.epsilon
        noise = np.random.normal(0, sigma)
        return value + noise
    
    def private_mean(self, values: List[float]) -> float:
        """Compute differentially private mean."""
        mean = np.mean(values)
        return self.add_laplace_noise(mean)
    
    def private_correlation(self, x: List[float], y: List[float]) -> float:
        """Compute differentially private correlation."""
        from scipy.stats import pearsonr
        r, _ = pearsonr(x, y)
        return self.add_laplace_noise(r)
    
    def private_histogram(self, values: List[float], bins: int = 10) -> np.ndarray:
        """Compute differentially private histogram."""
        hist, _ = np.histogram(values, bins=bins)
        private_hist = np.array([self.add_laplace_noise(h) for h in hist])
        private_hist = np.maximum(private_hist, 0)  # Clip negative values
        return private_hist

        self.privacy = DifferentialPrivacy(
            epsilon=privacy_params.get('epsilon', 1.0),

        )
    
    def query_population_entropy(self, roi_name: str, diagnosis: str = None):
        """
        Query population entropy across all nodes.
        
        Returns differentially private aggregate statistics.
        """
        results = []
        
        for node in self.nodes:
            # Send query to node
            node_result = self.query_node(node, roi_name, diagnosis)
            if node_result:
                results.append(node_result)
        
        # Aggregate results with differential privacy
        mean_values = [r['mean_gradient'] for r in results if 'mean_gradient' in r]
        std_values = [r['std_gradient'] for r in results if 'std_gradient' in r]
        counts = [r['count'] for r in results if 'count' in r]
        
        private_mean = self.privacy.private_mean(mean_values)
        private_std = self.privacy.add_laplace_noise(np.mean(std_values))
